# Unit Economics Calculator

Калькулятор юнит-экономики для оценки стоимости привлечения клиентов, их ценности, маржинальности и окупаемости.

В работе я собрал основные показатели в единый интерфейс, продумал ввод исходных данных и наглядное представление расчётов. Проект помогает сравнивать сценарии и понимать, как изменение отдельных параметров влияет на результат.
